## 页面状态与交互流程

这张图回答：用户如何进入原型、完成关键交互，并看到成功、空数据或失败状态？

```mermaid
flowchart LR
    ENTRY["进入原型页面"] --> LOAD{"数据/模拟状态"}
    LOAD -->|有数据| READY["可操作状态"]
    LOAD -->|无数据| EMPTY["空状态与下一步"]
    LOAD -->|失败| ERROR["错误状态与恢复入口"]
    READY --> ACTION["执行关键交互"]
    ACTION --> RESULT["显示确认结果"]
```

关键结论：

- 原型覆盖正常、空数据和失败状态，而不只展示理想截图。
- 所有交互结论必须回到需求流程、规则或 AC。
- 原型不验证真实 API、数据库、认证、生产数据或性能。

## 验收路径

```mermaid
flowchart LR
    C["最终候选"] --> A["AC 与业务规则追溯"]
    A --> T["风险匹配验证"]
    T --> R{"验收结论"}
    R -->|通过| D["交付收口"]

    R -->|阻断| B["Bugfix"]
    B --> C
```

关键结论：验收失败回到修复或文档阶段，修复后重新验证同一范围；不得在本阶段修改生产代码。

## 故障与恢复路径

这张图回答：故障如何被发现、止血、修复、验证并恢复服务？

```mermaid
flowchart LR
    INCIDENT["故障触发/告警"] --> IMPACT["确认用户和数据影响"]
    IMPACT --> CONTAIN["临时止血<br/>限制影响扩大"]
    CONTAIN --> ROOT["定位并验证根因"]
    ROOT --> FIX["永久修复"]
    FIX --> VERIFY{"回归与生产验证通过？"}
    VERIFY -->|是| RECOVER["恢复服务并观察"]
    VERIFY -->|否| ROLLBACK["回退或继续止血"]
    RECOVER --> FOLLOW["补偿任务与复盘"]
```

关键结论：

- 止血只控制影响，不得被描述为永久修复。
- 根因必须有复现或证据链，不能只根据最后一个报错猜测。
- 恢复需要验证和观察；失败时执行明确回退。
